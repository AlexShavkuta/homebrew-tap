# AlexShavkuta/homebrew-tap

Homebrew formulas for my tools.

```sh
brew install AlexShavkuta/tap/pairmind
```

| Tool | Description |
|---|---|
| [pairmind](https://github.com/AlexShavkuta/pairmind) | Pair two coding agents peer-to-peer with a shared secret |

Formulas in `Formula/` are written automatically by each project's GoReleaser release workflow. Don't edit them by hand.
